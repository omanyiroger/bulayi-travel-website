 Bulayi Travel Agency Website

A modern marketing and showcase website built for Bulayi Travel Agency, a Nairobi-based travel agency helping clients plan flights, holidays, accommodation, visa assistance, and travel experiences.

The website is designed to establish an online presence, showcase Bulayi's services and destinations, build customer trust, and provide direct channels for travel enquiries.

 🌍 Live Website

Website: https://bulayitravel.com

📌 About the Project

The Bulayi Travel Agency website was developed as a professional business website using **Django and Python**.

The project focuses on presenting the agency's services and brand online while making it easy for potential clients to contact the business and begin planning their trips.

It is a **marketing and information website**, not an online booking engine. Flight booking and future GDS integrations are handled separately from the website.

 🚀 Running the Project Locally

 1. Clone the repository

```bash
git clone https://github.com/omanyiroger/bulayi-travel-website.git
cd bulayi-travel-website
```

 2. Create a virtual environment

```bash
python3 -m venv venv
```

 3. Activate the virtual environment

Linux/macOS:

```bash
source venv/bin/activate
```

Windows:

```bash
venv\Scripts\activate
```

 4. Install dependencies

```bash
pip install -r requirements.txt
```

 5. Run database migrations

```bash
python manage.py migrate
```

 6. Start the development server

```bash
python manage.py runserver
```

The website will then be available at:

```text
http://127.0.0.1:8000/
```
